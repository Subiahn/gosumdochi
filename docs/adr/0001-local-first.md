# ADR-0001: 로컬 단일 에이전트와 타입 지정 판단

상태: 제안 · 2026-10-18

## 결정

1. Mac의 Ollama와 Docker의 Go 에이전트·실습 앱을 분리한다.
2. 첫 버전은 단일 모델을 Planner/Judge 역할로 순차 사용한다.
3. Judge는 enum과 참조 ID로 결정하고 실행 권한은 Policy가 강제한다.
4. 단일 에이전트·순차 도구·파일 저장으로 시작한다.
5. 실습 앱은 SQLite를 포함하며 별도 DB 컨테이너는 만들지 않는다.
6. 실제 Jev 연동은 제공자 계약이 확인될 때까지 구현하지 않는다.

## 이유와 비용

16GB 장비에서 여러 모델·브라우저·DB를 동시에 실행하는 부담을 줄인다. 제공자를 바꿀 수 있도록 인터페이스를 유지한다. Planner와 Judge를 같은 모델로 실행하면 추가 호출 비용은 생기고 오류의 상관관계도 남는다. 따라서 속도 향상이나 독립 검증을 주장하지 않는다.
파일 저장은 초기 개발이 단순하지만 다중 실행 검색과 재개에 불리하다. 그 요구가 생기면 Store 인터페이스 아래 SQLite로 이전한다.
control 네트워크가 있는 agent는 완전한 egress 격리 환경이 아니다. 이 한계는 SDD에 명시하고 HTTP 도구의 연결 경계 테스트로 보완한다.
